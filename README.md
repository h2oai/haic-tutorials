# H2O AI Cloud Code Samples and Tutorials

Get started with the H2O Soverign AI Platform; specifically the Managed Cloud 26.10 release. 

## Running in the Notebook Engine

These tutorials were explicitly tested from a Notebook Engine running in Managed Cloud v26.09.1. Running in this envirionment will automatically handle the Python version, needed library versions, and authentication.
